# Manufacturing Equipment Output Prediction with Linear Regression

## 📌 Project Overview

This project is a Data Science Capstone Project focused on predicting manufacturing equipment output using Machine Learning.

The project uses **Linear Regression** to predict the number of parts produced per hour based on manufacturing-related features.

## 🎯 Objective

The main objective is to build a regression model that can predict:

**Parts Per Hour (`Parts_Per_Hour`)**

The project also compares the performance of Linear Regression with **Ridge Regression**.

## 🧠 Machine Learning Approach

- Supervised Learning
- Regression
- Linear Regression
- Ridge Regression
- 5-Fold Cross-Validation

## 📊 Dataset

The dataset contains **1,000 hourly manufacturing observations** and **19 columns**.

The target variable is:

`Parts_Per_Hour`

The dataset is stored in:

`manufacturing_dataset_1000_samples.csv`

## 🔍 Project Steps

1. Data Loading
2. Exploratory Data Analysis
3. Missing Value Handling
4. Outlier Inspection
5. Data Preprocessing
6. Linear Regression Model
7. Ridge Regression Model
8. Model Evaluation

## 📈 Evaluation Metrics

The models are evaluated using:

- R² Score
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- Mean Absolute Error (MAE)
